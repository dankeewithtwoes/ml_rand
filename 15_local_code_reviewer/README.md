# Проверка Python-кода

По умолчанию `review.py` ищет выбранные конструкции регулярными выражениями: eval/exec, небезопасные вызовы оболочки, возможную конкатенацию SQL и строки с ключами. Замечания можно сохранить в SARIF. Флаг `--llm` добавляет проверку через настроенный OpenAI-совместимый endpoint.

## Запуск

Из этой папки:

```bash
pip install -r requirements.txt
python review.py --file app.py --sarif report.sarif
python review.py --diff HEAD~1
python review.py --file app.py --llm
python benchmark_vs_static.py --output demo/review_benchmark.json
```

Для `--diff` нужен Git-репозиторий и существующая ссылка на коммит. Для `--llm` нужен доступный сервер; исходный код передаётся этому серверу.

## Ограничения

Регулярные выражения не анализируют поток данных и могут ошибаться. Бенчмарк использует четыре синтетических примера; интеграции с Semgrep/Bandit в нём нет. Результат небольшой выборки не определяет качество проверки произвольного проекта. Ошибки Git и LLM-вызова не считаются успешной проверкой.
