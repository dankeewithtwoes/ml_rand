# Поиск по документам и RAG

`rag_engine.py` объединяет BM25 и поиск по эмбеддингам в Chroma, затем ранжирует фрагменты cross-encoder моделью и передаёт их LLM. Для ответов используется OpenAI-совместимый API или Ollama.

`grounding.py` проверяет пересечение слов каждого предложения ответа со словами найденных фрагментов. Он работает отдельно от моделей и возвращает предложения с недостаточным покрытием.

## Запуск

Проверка на локальных примерах, из этой папки:

```bash
python examples/grounding_demo.py
python -m unittest discover -s tests -v
```

Для полного RAG нужны зависимости, модели и доступный LLM endpoint:

```bash
pip install -r requirements.txt
cp .env.example .env
python rag_chat.py "What are the benefits of Product A?"
python evaluate_rag.py
```

## Ограничения

Примеры проверки предложений сохранены в [grounding_report.json](examples/grounding_report.json). Полный путь BM25 → Chroma → reranker → LLM этим тестом не проверяется.

Лексическое покрытие не определяет истинность утверждения: перефразирование может снизить оценку, а повторение ключевых слов — повысить её. Порог нужно подбирать для своих документов. Метрики `evaluate_rag.py` — приближённые оценки, а не независимая разметка качества ответа. При выборе внешнего API фрагменты документов передаются этому провайдеру; `.env` с ключами хранится локально.
