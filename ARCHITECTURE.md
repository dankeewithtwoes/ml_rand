# Архитектура портфолио

Проекты — отдельные лабораторные работы на тему ML и локальных LLM. У них общий фокус на локальном запуске, измерении поведения и обработке данных, но запуск одного проекта не требует остальных.

## Группы проектов

| Направление | Проекты |
|---|---|
| Обучение и данные | 01 PyTorch classifier, 02 LoRA tuning, 13 Fine-tuning Lab, 16 Synthetic Data Factory |
| Поиск и приложения | 03 RAG, 04 LlamaIndex agent, 08 Dify workflow, 11 Knowledge OS, 12 Voice Companion, 17 Document Parser |
| Инференс и инфраструктура | 05 Local LLM Arena, 06 GGUF benchmark, 07 vLLM, 14 Model Router, 19 Edge Fleet |
| Безопасность и наблюдаемость | 10 Code Repair Agent, 15 Code Reviewer, 18 AI Observability, 20 Red-Team Arena |
| Генерация и инструменты | 09 ComfyUI pipeline, 21 Skill Forge |

## Общие потоки

В некоторых сценариях проекты можно соединить: синтетические данные или fine-tuning — с локальным инференсом; Document Parser или RAG — с Model Router; трассировку и red-team результаты — с проверками при обновлении модели. Эти связи описывают возможные интеграции, а не обязательную последовательность запуска.

## Проверка

Запустите python quality_gate.py из корня, чтобы выполнить офлайн-проверки портфолио. Для установки каждой лаборатории используйте её собственный README и requirements-файл. Внешние API, модели и GPU могут потребовать отдельной настройки.
