# Исправление Python-кода с проверкой патча

`agent.py` передаёт исходный файл и ошибки тестов LLM, сохраняет предложенное исправление и повторно запускает тесты. `repair_policy.py` отдельно проверяет синтаксис, размер изменений и запрещённые вызовы. Наличие проверки в этом модуле не означает, что любой путь запуска агента изолирован.

## Проверка правил

Из этой папки:

```bash
pip install -r requirements.txt
python demo_policy_gate.py
python -m pytest test_repair_policy.py -q
```

Примеры решений сохранены в [policy_gate_report.json](demo/policy_gate_report.json).

## Запуск агента

Настройте `.env` по `.env.example`, затем:

```bash
python agent.py --file sample_bug.py --tests test_sample_bug.py
```

## Ограничения

Проверка AST блокирует выбранные конструкции, но не заменяет изоляцию процесса. Тесты и изменённый код исполняются с правами пользователя. Используйте отдельную копию проекта и просматривайте патч. При внешнем endpoint исходный код и ошибки передаются провайдеру. Демонстрация правил не проверяет качество исправлений живой моделью.
