# Проверка устойчивости LLM к тестовым атакам

Скрипты отправляют шаблоны jailbreak, toxicity и fuzzing на OpenAI-совместимый сервер. `safety_metrics.py` рассчитывает частоты, интервалы Уилсона и число ошибок инфраструктуры. Ошибка запроса учитывается отдельно от оценённого ответа модели.

## Проверка статистики

Из этой папки:

```bash
pip install -r requirements.txt
python examples/run_offline_demo.py
python -m unittest discover -s tests -v
```

Демонстрация использует синтетические записи и недоступный тестовый endpoint. Вывод находится в [offline_safety_report.json](examples/offline_safety_report.json); это не измерение безопасности живой модели.

## Проверка модели

Нужен работающий сервер и установленные модели:

```bash
python redteam.py --model llama3.1 --attacks jailbreak,toxicity,fuzzing --count 30
python compare_safety.py --models llama3.1,phi3,qwen2.5
python report.py --input demo/redteam.json
```

## Ограничения

Небольшой набор шаблонов не обеспечивает полного покрытия атак. Оценка отказов и токсичности основана на подстроках; интервал Уилсона описывает выборочную неопределённость, но не исправляет ошибки этой эвристики. Повторение шаблонов нарушает предположение о независимости наблюдений. Для точного сравнения используйте исходные записи, а не округлённые групповые оценки. Запросы и ответы сохраняются локально; сетевое назначение определяется endpoint.
