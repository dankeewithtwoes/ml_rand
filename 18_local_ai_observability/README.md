# Прокси для журналирования и фильтрации LLM-запросов

Flask-прокси стоит между клиентом и OpenAI-совместимым сервером. Правила блокируют выбранные персональные данные, токсичные фразы и попытки подмены инструкций. Разрешённый запрос передаётся серверу модели; события записываются локально. `policies.py` формирует сводку с длиной и хешем промпта без его исходного текста.

## Проверка

Из этой папки:

```bash
pip install -r requirements.txt
python run_demo.py
python -m unittest test_policies -v
```

`run_demo.py` поднимает локальный тестовый endpoint. Пример вывода: [demo_output.txt](docs/demo_output.txt).

## Подключение модели

При работающем Ollama:

```bash
python guard_proxy.py --target http://localhost:11434/v1 --port 11435
```

В другом терминале:

```bash
python example_client.py --prompt "Hello"
python dashboard.py
```

## Ограничения

Фильтры основаны на регулярных выражениях и списках слов, поэтому возможны пропуски и ложные срабатывания. Хеш промпта не равнозначен шифрованию. Сводка без исходного промпта не гарантирует отсутствие чувствительных данных во всех остальных логах. Демонстрация с тестовым endpoint не измеряет качество модели; потоковые ответы и нетекстовые сообщения пока отклоняются явно.
