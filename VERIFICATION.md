# Проверка проектов — 16 октября 2026

Проверка выполнена на Windows, Python 3.12, CPU. Для каждого проекта проверена хотя бы одна выполняемая функция. Полный запуск с предобученными моделями подтверждён только там, где это прямо указано; проверка отдельной функции не заменяет проверку всей системы.

## Автоматическая проверка

```bash
python -m pip install -r requirements-dev.txt
python quality_gate.py --json
```

Команда проверяет каталоги всех 21 проектов, компилирует Python, запускает корневой набор, тесты Skill Forge и отдельные тесты модулей. HTTP-тесты поднимают локальный сервер с заданными ответами. Они проверяют адреса, параметры и обработку ошибок, а не качество модели. CI настроен на Linux и Windows; его фактический статус виден в GitHub Actions.

## Интерфейс и среда

Все 21 примера проверяются через FastAPI и отдельно через HTTP к запущенному локальному серверу. Также проверяются история, оценка результата, удаление и отклонение некорректных входных данных.

Браузерная проверка в Chromium прошла после изменения разрешений среды: запущены все 21 примера, проверены оценка результата, скачивание JSON, ошибки входа, повторный запуск, поиск, категории, история и удаление. При ширинах 320, 390 и 768 пикселей переполнения страницы нет; запуск примера также работает. Ошибок JavaScript не зарегистрировано.

Ollama, ComfyUI, vLLM и LM Studio на стандартных локальных портах во время проверки не работали. Крупные веса не скачивались, платные API не вызывались.

В первом локальном запуске тестовый harness использовал наследуемые разрешения для временных каталогов внутри рабочей папки: Windows-ACL каталогов `0700` был недоступен ограниченному токену того запуска. Эта настройка не включена в проект. GitHub Actions выполняет обычные тесты.

## Совместимость SDK

RAG использует `langchain-classic` для EnsembleRetriever согласно [официальному справочнику](https://reference.langchain.com/python/langchain-classic/retrievers/ensemble/EnsembleRetriever). Версии зависимостей относятся к одной семье LangChain 1.x. Для синхронного ReAct-агента закреплена семья LlamaIndex core 0.12; локальный endpoint подключается через [OpenAILike](https://developers.llamaindex.ai/python/framework-api-reference/llms/openai_like/). Полный запуск LlamaIndex в этой среде не проверен.
