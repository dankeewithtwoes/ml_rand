# Состояние проектов

В репозитории 21 учебный прототип. Корневые тесты проверяют отдельные функции: расчёт метрик, обработку данных, выбор моделей, хранение и контракты инструментов. Работа с моделями, GPU и внешними сервисами требует отдельных запусков.

Часть проектов содержит незавершённые скрипты. В частности, `13_local_finetuning_lab/eval.py` ещё не вычисляет perplexity, а конвертация в GGUF выполняется отдельно через llama.cpp. Ограничения каждого проекта описаны в его README.

Дальнейшая работа:

- Проверить установку и основные команды в чистом окружении.
- Собрать размеченные выборки для RAG, парсера и оценки ответов.
- Измерить задержки и качество при одинаковых настройках моделей.
- Проверить реальные вызовы инструментов на двух LLM-провайдерах.
- Добавить потоковые ответы в прокси и импорт данных в хранилище заметок.

Для публикации результатов сохраняйте исходный вывод вместе с конфигурацией запуска. Успешный локальный тест функции не подтверждает весь сценарий проекта.
